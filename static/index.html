📖 사용 가이드

🚀 시작하기

이 챗봇은 업로드된 문서의 내용을 기반으로 질문에 답변합니다.

  • 지원 형식: PDF, HWP, HWPX, DOC, DOCX, XLS, XLSX, PPT, PPTX, TXT (총 10가지)
  • 사용자 인증: 로그인 후 개인화된 대화 관리 및 문서 접근
  • 질문하기: 하단 입력창에 질문을 입력하고 Enter 또는 전송 버튼 클릭
  • AI 답변: 문서 내용을 분석하여 실시간으로 답변 생성

🔐 사용자 인증

개인화된 서비스를 위한 사용자 인증 기능을 제공합니다.

  • 회원가입: 이메일과 비밀번호로 새 계정 생성
  • 로그인: 등록된 계정으로 안전하게 로그인
  • 세션 관리: 자동 로그인 유지 및 보안 세션 관리
  • 비밀번호 변경: 프로필 메뉴에서 언제든지 비밀번호 변경 가능
  • 비밀번호 재설정: 로그인 화면의 "비밀번호를 잊으셨나요?" 링크를 통해 이메일 또는 OTP(2FA) 방식으로 비밀번호 재설정 가능
  • 로그아웃: 우측 상단 프로필 메뉴에서 안전하게 로그아웃
  • 보안 로깅: 모든 로그인/로그아웃 이벤트가 기록되어 보안 강화

🔑 2단계 인증 (2FA)

Google Authenticator, Microsoft Authenticator 등 TOTP 앱을 사용한 추가 보안 인증입니다.

📱 2FA 활성화하기

  • 설정 접근: 우측 상단 프로필 메뉴 → "2FA 설정" 클릭
  • QR 코드 스캔: 인증 앱으로 화면의 QR 코드를 스캔
  • 코드 확인: 앱에 표시된 6자리 코드 입력하여 활성화 완료
  • 백업 코드: 표시되는 백업 코드를 안전한 곳에 저장하세요

🔐 2FA 로그인

  • 1단계: 이메일과 비밀번호를 입력합니다
  • 2단계: 인증 앱에서 현재 표시된 6자리 코드를 입력합니다
  • 코드 갱신: 코드는 30초마다 변경되니 현재 코드를 입력하세요
  • 만료 주의: 코드가 곧 만료될 것 같으면 다음 코드를 기다리세요

❌ 2FA 비활성화

  • 비활성화: 프로필 메뉴 → "2FA 설정" → "2FA 비활성화" 버튼 클릭
  • 코드 확인: 비활성화 시에도 현재 인증 코드 입력 필요

⚠️ 주의: 휴대폰을 분실하거나 앱을 삭제하면 로그인이 불가능할 수 있습니다. 백업 코드를 안전한 곳에 보관하거나, 관리자에게 2FA 초기화를 요청하세요.

💡 팁: 2FA는 비밀번호가 유출되더라도 계정을 보호하는 강력한 보안 기능입니다. 보안이 중요한 환경에서는 반드시 활성화하세요.

🏢 조직 및 권한

조직 기반 문서 접근 권한 관리로 안전하고 효율적인 문서 검색을 제공합니다.

  • 조직 소속: 모든 사용자는 하나의 조직에 속하며, 우측 상단에 조직명이 표시됩니다
  • 문서 격리: 자신의 조직에 속한 문서만 검색할 수 있어 데이터 보안이 강화됩니다
  • 그룹 격리: 조직별로 분리된 그룹 구조로 문서를 효율적으로 관리합니다
  • 자동 필터링: 검색 시 자동으로 조직 범위로 제한되어 별도 설정이 불필요합니다
  • 조직 전환: 관리자가 조직을 변경하면 접근 가능한 문서가 달라집니다
  • 멀티 테넌트: 여러 부서나 팀이 하나의 시스템을 안전하게 공유할 수 있습니다

💬 대화 관리

모든 대화를 저장하고 관리할 수 있는 강력한 대화 관리 기능을 제공합니다.

  • 대화 저장: 모든 질문과 답변이 자동으로 서버에 저장됩니다
  • 히스토리 사이드바: 좌측 사이드바에서 모든 이전 대화 확인 (Ctrl/Cmd + H)
  • 대화 제목: 첫 질문 기반으로 자동 생성되는 대화 제목
  • 대화 불러오기: 이전 대화를 클릭하여 즉시 불러오기
  • 대화 북마크: ⭐ 별표 아이콘을 클릭하여 중요한 대화를 북마크로 표시
  • 북마크 필터: 사이드바 상단의 북마크 버튼으로 북마크된 대화만 필터링
  • 대화 삭제: 각 대화의 삭제 버튼으로 불필요한 대화 제거
  • 대화 검색: 검색창으로 특정 대화 빠르게 찾기
  • 새 대화: "새 대화" 버튼 또는 Ctrl/Cmd + K로 새로운 대화 시작
  • 문맥 유지: 불러온 대화의 전체 문맥이 유지되어 연속 질문 가능

📥 대화 내보내기

대화 내용을 다양한 형식으로 내보내어 외부에서 활용할 수 있습니다.

  • 7가지 형식: JSON, 텍스트(TXT), 마크다운(MD), HTML, PDF, DOCX, HWPX 지원
  • JSON: 원본 데이터 구조 보존, 프로그래밍 활용에 최적
  • 텍스트: 단순 텍스트 형식, 모든 프로그램에서 열기 가능
  • 마크다운: 서식 보존, GitHub/노션 등에서 사용 가능
  • HTML: 웹 브라우저에서 서식과 함께 열기 가능
  • PDF: 인쇄 및 배포에 적합한 고정 레이아웃 형식
  • DOCX: Microsoft Word 형식으로 편집 및 공유 가능
  • HWPX: 한글(HWP) 호환 형식으로 한국 공공기관에서 활용
  • 내보내기: 헤더의 "내보내기" 버튼 또는 Ctrl/Cmd + E
  • 타임스탬프: 모든 형식에 날짜와 시간 정보 포함

📤 대화 가져오기

이전에 내보낸 대화 파일을 불러와서 계속 이어갈 수 있습니다.

  • 7가지 형식 지원: JSON, TXT, MD, HTML, PDF, DOCX, HWPX 파일 모두 가능
  • 자동 파싱: 파일 확장자를 자동으로 감지하여 적절히 파싱
  • 가져오기: 헤더의 "가져오기" 버튼 또는 Ctrl/Cmd + I
  • 덮어쓰기 확인: 현재 대화가 있으면 덮어쓸지 확인
  • 대화 복원: 가져온 대화 내용이 화면에 자동으로 표시
  • 호환성: 내보내기로 생성된 모든 형식의 파일 가져오기 가능

💡 추천 질문 사용하기

페이지가 로딩되면 문서 기반 추천 질문이 자동으로 표시됩니다.

  • 자동 생성: AI가 문서 내용을 분석하여 관련 질문을 추천합니다
  • 클릭 한 번: 추천 질문을 클릭하면 자동으로 질문이 전송됩니다
  • 자동 숨김: 첫 질문 후 추천 질문은 자동으로 숨겨집니다
  • 시작점: 어떤 질문을 해야 할지 모를 때 유용합니다

💭 후속 질문

AI 답변 후 관련된 후속 질문을 자동으로 제안합니다.

  • 자동 생성: 답변 내용을 분석하여 3개의 후속 질문 생성
  • 문맥 연결: 이전 답변과 자연스럽게 이어지는 질문
  • 원클릭 질문: 제안된 질문을 클릭하면 즉시 전송
  • 대화 확장: 주제를 더 깊이 탐구하고 싶을 때 유용
  • 한국어 최적화: 자연스러운 한국어 질문 생성

🔄 스마트 대화 기능

이전 대화 내용을 기억하여 연속적인 질문이 가능합니다.

  • 대화 기록: 모든 질문과 답변이 자동으로 저장됩니다
  • 문맥 이해: "그것은 무엇인가요?", "더 자세히 설명해주세요" 같은 후속 질문 가능
  • 대화 흐름: 이전 답변을 참조하여 더 정확한 답변 제공
  • 세션 저장: 대화 내용이 서버와 브라우저에 모두 저장
  • 자동 복원: 페이지 새로고침 시 이전 대화가 자동으로 복원됩니다

✨ 질문 자동완성

입력 중 추천 질문이 자동으로 제안됩니다.

  • 자동 제안: 2글자 이상 입력 시 관련 질문 자동 표시
  • 퍼지 매칭: 유사한 단어도 인식하여 질문 추천
  • 키보드 네비게이션: ↑/↓ 화살표로 항목 이동, Enter로 선택
  • 마우스 선택: 제안된 질문을 클릭하여 자동 입력
  • ESC 닫기: ESC 키로 자동완성 닫기

👍 피드백 시스템

AI 답변에 대한 피드백을 제공하여 서비스 품질 향상에 기여할 수 있습니다.

  • 답변 평가: 각 답변 하단의 👍/👎 버튼으로 평가
  • 상세 피드백: 평가 후 구체적인 피드백 작성 가능
  • 개선 기여: 피드백이 AI 모델 개선에 활용됩니다
  • 시각적 표시: 평가한 답변은 하이라이트로 표시
  • 재평가 가능: 언제든지 평가 변경 가능

🔍 문서 및 그룹 필터링

특정 문서나 그룹만 선택하여 검색 범위를 좁힐 수 있습니다.

📄 문서 필터

  • 필터 열기: "문서 필터 ▼" 버튼 또는 Ctrl/Cmd + B
  • 문서 선택: 체크박스를 사용하여 검색할 문서 선택
  • 전체 선택: "전체 선택" 버튼으로 모든 문서 한 번에 선택
  • 전체 해제: "전체 해제" 버튼으로 모든 선택 해제
  • 조직 범위: 자신의 조직에 속한 문서만 표시됩니다

📁 그룹 필터

  • 그룹별 검색: 문서 대신 그룹 단위로 검색 범위 지정 가능
  • 계층 구조: 상위 그룹 선택 시 하위 그룹의 모든 문서 포함
  • 조직 격리: 자신의 조직에 속한 그룹만 표시됩니다
  • 필터 모드: "조직 내 전체 그룹" 또는 "선택한 그룹만" 선택 가능
  • 정확도 향상: 주제별로 그룹화된 문서로 검색 정확도 향상

💡 팁: 검색 범위를 좁힐수록 더 정확하고 관련성 높은 답변을 받을 수 있습니다. 그룹 필터를 활용하면 주제별로 효율적인 검색이 가능합니다.

📝 답변 확인하기

AI가 생성한 답변과 참조 출처를 확인할 수 있습니다.

  • 실시간 스트리밍: 답변이 생성되는 과정을 실시간으로 표시
  • 진행 상황: 타이핑 인디케이터와 토큰 카운트로 진행률 확인
  • 마크다운 지원: 코드 블록, 리스트, 표 등 다양한 서식 지원
  • 출처 표시: 각 답변 하단에 참조한 문서 출처가 표시됩니다
  • 출처 상세: 출처 박스를 클릭하면 원문 내용을 확인할 수 있습니다
  • 관련도 점수: 각 출처의 관련성 점수가 표시됩니다

⚠️ 에러 처리

오류 발생 시 친절한 메시지와 복구 옵션을 제공합니다.

  • 친절한 메시지: 사용자가 이해하기 쉬운 에러 설명
  • 다시 시도: "다시 시도" 버튼으로 즉시 재시도 가능
  • 자동 복구: 일시적 네트워크 오류는 자동으로 재시도
  • 에러 유형: 네트워크, 서버, 문서 처리 등 다양한 에러 대응
  • 안내 메시지: 문제 해결을 위한 구체적인 조치 안내

로컬 문서뿐만 아니라 웹 검색과 공식 문서를 활용한 포괄적인 검색 기능입니다.

📊 검색 모드

  • 🎯 스마트 (기본): 질문을 분석하여 자동으로 최적의 검색 소스 선택
    • 일반 질문 → 로컬 문서 검색
    • 최신 정보 필요 → 웹 검색 추가
    • 기술 관련 질문 → 공식 문서 검색 추가
  • 📚 로컬 문서만: 업로드된 문서에서만 검색 (기존 방식)
  • 🌐 로컬 + 웹 검색: 로컬 문서와 실시간 웹 검색 결과를 함께 활용
  • 🔍 모든 소스: 로컬 + 웹 + 공식 문서를 모두 활용한 종합 검색
  • 🔧 외부 도구만: 웹 검색과 공식 문서만 사용 (로컬 문서 제외)

🌐 웹 검색 프로바이더

  • Tavily (클라우드): 빠르고 안정적인 클라우드 기반 웹 검색 (API 키 필요)
  • SearXNG (자체 호스팅): 개인 서버에서 운영하는 메타 검색 엔진
    • Google, Bing, DuckDuckGo, GitHub, StackOverflow 등 다중 소스 통합
    • Crawl4AI 연동으로 웹 페이지 전체 내용 추출 (더 정확한 답변)
    • 외부 API 의존 없이 운영 가능

✨ 장점

  • 최신 정보: 웹 검색으로 실시간 뉴스, 기술 동향 파악
  • 공식 문서: React, Vue, Spring Boot 등 프레임워크 공식 문서 검색
  • 포괄적 답변: 로컬 문서의 제약을 넘어 더 넓은 정보 활용
  • 자동 출처 구분: [로컬 문서], [웹 검색], [공식 문서] 태그로 출처 명시
  • 콘텐츠 강화: SearXNG + Crawl4AI 사용 시 웹 페이지 전체 내용 활용

⚠️ 참고: 하이브리드 RAG 기능은 관리자가 활성화한 경우에만 사용 가능합니다. 비활성화 상태에서는 "로컬 문서만" 모드로 고정됩니다.

⚙️ 설정

우측 상단 설정 버튼으로 다양한 옵션을 조정할 수 있습니다.

🔍 검색 설정

  • 검색 개수 (Top K): 답변 생성 시 참조할 문서 개수 (1-10)
  • 검색 모드: 하이브리드 RAG 검색 모드 선택 (위 섹션 참조)
  • 캐시 임계값: 유사 질문 캐시 활용 기준 (0.0-1.0)
  • 캐시 유효시간: 캐시 보관 시간 (초 단위)

🤖 생성 설정

  • 온도 (Temperature): 답변의 창의성 조절 (0.0-1.0)
    • 낮은 값: 더 일관되고 정확한 답변
    • 높은 값: 더 창의적이고 다양한 답변
  • 최대 토큰 (Max Tokens): 답변 최대 길이 설정

🎨 화면 설정

  • 테마 설정: 다크/라이트 모드 전환 (Ctrl/Cmd + Shift + D)

💾 자동 저장: 모든 설정값은 변경 즉시 자동으로 브라우저에 저장됩니다. 별도로 "설정 저장" 버튼을 누를 필요가 없습니다.

🔊 TTS (음성 합성)

AI 답변을 음성으로 읽어주는 기능입니다. 관리자가 활성화한 경우에만 사용할 수 있습니다.

🎧 답변 음성 읽기

  • 음성 버튼: AI 답변 하단의 🔊 버튼을 클릭하면 해당 답변을 음성으로 읽어줍니다
  • 재생 중 정지: 재생 중인 버튼을 다시 클릭하면 음성이 정지됩니다
  • 자동 감지: TTS가 비활성화 상태이면 음성 버튼이 표시되지 않습니다

🔄 실시간 음성 읽기 (스트리밍 TTS)

  • 실시간 모드: 설정에서 "실시간 음성 읽기"를 활성화하면, AI 답변이 생성되는 동안 실시간으로 음성이 재생됩니다
  • 설정 위치: 설정 패널 → TTS (음성 합성) → 실시간 음성 읽기 토글
  • TTS 상태: 설정 패널에서 현재 TTS 활성화 여부와 사용 중인 모델을 확인할 수 있습니다

🤖 지원 모델

  • Edge TTS (Fast): Microsoft 클라우드 기반, 빠른 응답 속도
  • Qwen3 TTS 0.6B: 로컬 실행, 빠른 속도, 음성 복제 지원
  • Qwen3 TTS 1.7B: 로컬 실행, 고품질 음성 (속도 느림)

📋 재생 목록 (플레이리스트)

  • 목록 추가: AI 답변의 "목록에 추가" 버튼을 클릭하면 재생 목록에 추가됩니다
  • 전체 재생: 재생 목록의 ▶ 버튼을 클릭하면 추가된 답변을 순서대로 자동 재생합니다
  • 개별 관리: 각 항목을 개별 재생하거나 목록에서 제거할 수 있습니다
  • 전체 삭제: 재생 목록의 🗑️ 버튼으로 전체 목록을 비울 수 있습니다
  • 플로팅 버튼: 화면 하단의 플로팅 버튼으로 재생 목록 패널을 열고 닫을 수 있습니다

💡 팁: TTS 모델과 언어 설정은 관리자 페이지에서만 변경 가능합니다. 음성 품질이나 속도에 문제가 있으면 관리자에게 문의하세요.

🔧 시스템 정보

현재 시스템에서 사용 중인 AI 모델 정보입니다.

  • 임베딩 모델: KURE-v1 (Korean Universal Representation Embeddings)
    • 1024차원 벡터로 한국어 의미 검색에 최적화
    • 문서를 벡터로 변환하여 의미적 유사도 계산
  • LLM 모델: Qwen3-30B (4-bit 양자화)
    • 고성능 다국어 대화형 AI 모델
    • 한국어 질의응답에 최적화된 30B 파라미터 모델
    • 약 20GB RAM 사용 (4-bit 양자화로 메모리 최적화)
  • 문서 처리: Document Service (Java Spring Boot)
    • 다양한 문서 형식을 텍스트로 추출
    • Apache POI, PDFBox 기반 고성능 처리

❓ 자주 묻는 질문 (FAQ)

Q1. 답변이 "문서에 정보가 없습니다"라고 나와요

A: 다음을 확인해보세요:
1. 문서 필터에서 올바른 문서가 선택되었는지 확인
2. 조직 범위 내의 문서인지 확인 (조직명 확인)
3. 질문을 더 구체적으로 바꿔서 다시 시도
4. 하이브리드 RAG 모드를 "스마트" 또는 "모든 소스"로 변경

Q2. 로그인이 계속 풀려요

A: 브라우저 쿠키 설정을 확인하세요. 사이트의 쿠키를 허용해야 로그인 상태가 유지됩니다. 시크릿 모드에서는 자동 로그인이 작동하지 않을 수 있습니다.

Q3. 문서를 업로드했는데 검색이 안 돼요

A: 문서 업로드 후 시스템이 인덱싱을 완료하는 데 시간이 걸립니다. 큰 문서의 경우 1-2분 정도 기다린 후 다시 시도해보세요. 시스템 상태에서 "준비 완료" 표시를 확인하세요.

Q4. 답변 생성이 느려요

A: AI 모델이 문서를 검색하고 답변을 생성하는 데 시간이 필요합니다. 특히 하이브리드 RAG 모드에서는 외부 검색도 진행되어 더 오래 걸릴 수 있습니다. 일반적으로 10-30초 정도 소요됩니다.

Q5. 이전 대화를 찾을 수 없어요

A: 좌측 사이드바의 대화 히스토리를 확인하세요 (Ctrl/Cmd + H). 검색 기능을 사용하면 키워드로 빠르게 찾을 수 있습니다. 중요한 대화는 ⭐ 북마크로 표시해두면 나중에 쉽게 찾을 수 있습니다.

Q6. 출처 문서를 볼 수 없어요

A: 답변 하단의 "📚 참고 문서" 섹션을 확인하세요. 각 문서를 클릭하면 AI가 참조한 원문 내용이 모달로 표시됩니다. 조직 권한 때문에 일부 문서는 접근이 제한될 수 있습니다.

Q7. 한국어 외 다른 언어도 지원하나요?

A: 네, 영어를 포함한 다국어를 지원합니다. 다만 한국어에 최적화되어 있어 한국어 질문과 답변이 가장 정확합니다.

Q8. 설정을 변경했는데 적용이 안 돼요

A: 대부분의 설정은 즉시 적용됩니다. 페이지를 새로고침해도 설정이 유지됩니다. 만약 적용이 안 된다면 브라우저 캐시를 삭제하거나 시크릿 모드에서 테스트해보세요.

Q9. 음성 버튼(🔊)이 보이지 않아요

A: TTS(음성 합성) 기능은 관리자가 활성화한 경우에만 사용 가능합니다. 음성 버튼이 보이지 않으면 관리자에게 TTS 기능 활성화를 요청하세요. 이미 활성화된 경우 페이지를 새로고침(F5)하면 반영됩니다.

Q10. 음성이 재생되다가 중간에 끊겨요

A: 긴 답변의 경우 음성 합성에 시간이 더 걸릴 수 있습니다. 네트워크 상태를 확인하고, 문제가 지속되면 관리자에게 TTS 모델 변경(Edge TTS 권장)을 요청하세요.

🔧 문제 해결

⚠️ 일반적인 문제

문제: 페이지가 하얗게 표시되거나 로딩이 안 됨

해결:

  • Ctrl + Shift + R (또는 Cmd + Shift + R)로 강력 새로고침
  • 브라우저 캐시 삭제 후 재접속
  • 다른 브라우저로 접속 시도 (Chrome, Edge, Firefox)
  • 브라우저 확장 프로그램 비활성화 후 재시도

문제: 네트워크 오류 (연결 실패)

해결:

  • 인터넷 연결 상태 확인
  • VPN 사용 중이면 비활성화 후 재시도
  • "다시 시도" 버튼 클릭 (자동 재시도 3회)
  • 서버 상태 확인 (관리자에게 문의)

문제: 답변이 중간에 끊김

해결:

  • 네트워크 연결 안정성 확인
  • 동일한 질문을 다시 전송
  • 설정에서 "최대 토큰" 값을 증가 (예: 2048 → 4096)
  • 질문을 더 짧고 명확하게 수정

문제: 한글 입력이 이상함

해결:

  • 브라우저를 최신 버전으로 업데이트
  • 한글 입력기 설정 확인 (Windows: 한/영 전환)
  • 다른 입력 필드(메모장 등)에서 작성 후 복사/붙여넣기

🔊 음성 관련 문제

문제: 음성 버튼이 보이지 않음

해결:

  • TTS는 관리자가 활성화해야 사용 가능합니다
  • 관리자에게 TTS 활성화를 요청하세요
  • 활성화 후 페이지를 새로고침하세요

문제: 음성이 재생되지 않거나 끊김

해결:

  • 인터넷 연결 상태 확인 (Edge TTS는 네트워크 필요)
  • 브라우저 오디오 권한이 허용되어 있는지 확인
  • 스트리밍 TTS 끊김 시: 설정에서 스트리밍 TTS를 끄고 답변 완료 후 음성 버튼 사용
  • 다른 브라우저로 시도 (Chrome, Edge 권장)
