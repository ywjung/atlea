# 사용자 페이지 도움말 정리 - 관리자 기능 제거

## 작업 개요

사용자 페이지(`static/index.html`)의 도움말 모달에서 관리자 전용 기능들을 제거하여 일반 사용자에게 필요한 기능만 표시하도록 정리했습니다.

## 제거된 섹션

### 1. 📋 문서 버전 관리 (완전 삭제)

**제거 이유**: 관리자 전용 기능

**이전 내용**:
- 자동 버전 생성
- 버전 목록 조회
- 버전 복원
- 버전 비교
- 버전 삭제
- 타임스탬프 관리

**영향**: 일반 사용자는 문서 버전 관리에 접근할 수 없으므로 도움말에서 제거

---

### 2. 📂 그룹 관리 (완전 삭제)

**제거 이유**: 관리자 전용 기능 (그룹 생성 및 편집)

**이전 내용**:
- 그룹 생성
- 문서 할당
- 그룹 필터링
- 시각적 표시
- 효율적 관리
- 검색 최적화

**영향**: 일반 사용자는 그룹을 생성하거나 관리할 수 없으므로 제거. 문서 필터링은 별도 섹션에 유지.

---

### 3. 🔌 API 문서 (개발자용) (완전 삭제)

**제거 이유**: 개발자/관리자 전용 기술 문서

**이전 내용**:
- Swagger UI 링크
- OpenAPI JSON 엔드포인트
- API 엔드포인트 목록
- 지원 형식 설명
- 테스트 방법
- 응답 형식 설명

**영향**: 일반 사용자에게는 API 문서가 필요 없으므로 제거

---

## 수정된 섹션

### 🔍 문서 필터링 섹션 업데이트

**변경 사항**: "그룹 필터" 항목 제거, "정확도 향상" 항목 추가

**이전**:
```
- 그룹 필터: 그룹별로 문서 필터링
```

**이후**:
```
- 정확도 향상: 필요한 문서만 선택하여 검색 정확도 향상
```

**이유**: 그룹 관리 기능이 제거되었으므로 그룹 필터링 언급 삭제

---

### 💡 사용 팁 섹션 업데이트

**변경 사항**: "그룹 관리" 팁 제거, "북마크 기능" 팁 추가

**제거된 팁**:
```
- 그룹 관리로 문서를 체계적으로 정리하면 검색 효율이 향상됩니다
```

**추가된 팁**:
```
- 대화 히스토리에서 ⭐ 북마크 기능으로 중요한 대화를 표시할 수 있습니다
```

**이유**: 사용자가 실제 사용할 수 있는 북마크 기능으로 대체

## 테스트 확인 사항

### 확인 방법
1. 사용자 페이지 접속 (http://localhost:8000)
2. F1 키 또는 도움말 버튼 클릭
3. 도움말 모달 확인

### 확인 항목
✅ "문서 버전 관리" 섹션 없음
✅ "그룹 관리" 섹션 없음
✅ "API 문서 (개발자용)" 섹션 없음
✅ "문서 필터링" 섹션에 그룹 필터 언급 없음
✅ "사용 팁"에 그룹 관리 언급 없음
✅ 총 17개 섹션 표시
✅ 모든 섹션이 사용자 관련 기능

## 향후 개선 방안

### 1. 역할 기반 도움말 동적 표시
현재는 정적으로 분리했지만, 향후 사용자 역할에 따라 동적으로 도움말을 표시할 수 있음:

```javascript
// 예시: 역할 기반 섹션 표시
if (user.role === 'admin') {
    showSection('document-version-management');
    showSection('group-management');
    showSection('api-documentation');
}
```

### 2. 컨텍스트 기반 도움말
사용자가 현재 보고 있는 화면에 맞는 도움말만 표시

### 3. 인터랙티브 튜토리얼
처음 사용하는 사용자를 위한 단계별 가이드 추가
