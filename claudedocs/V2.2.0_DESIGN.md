# v2.2.0 설계 문서 - Design Document

## 개요 (Overview)

v2.2.0은 엔터프라이즈급 기능을 도입하여 다중 사용자 환경에서 안전하고 격리된 사용을 가능하게 합니다.

### 핵심 목표
- 🔐 사용자 인증 및 세션 관리
- 🏢 다중 사용자 데이터 격리
- 🔑 API Key 기반 접근 제어
- 🎯 고급 필터링 (날짜, 페이지 범위)

---

## 1. 사용자 인증 시스템 (User Authentication System)

### 1.1 요구사항

**기능 요구사항:**
- 사용자 회원가입 (이메일 + 비밀번호)
- 로그인/로그아웃
- JWT 기반 토큰 인증
- 비밀번호 재설정
- 세션 관리 (자동 로그아웃)

**비기능 요구사항:**
- 비밀번호 해싱 (bcrypt, 최소 10 rounds)
- JWT 토큰 만료 (access: 1시간, refresh: 7일)
- HTTPS 필수 (프로덕션 환경)
- 브루트포스 공격 방지 (5회 실패 시 15분 잠금)

### 1.2 데이터 모델

**User 테이블 (Redis Hash)**
```python

    "user_id": "uuid-v4",
    "email": "user@example.com",

    "created_at": "2025-01-01T00:00:00Z",
    "last_login": "2025-01-01T12:00:00Z",

    "role": "user|admin",  # 추후 권한 관리용
    "failed_login_attempts": 0,
    "locked_until": null  # ISO timestamp or null
}
```

**Session 테이블 (Redis Hash with TTL)**
```python

    "session_id": "uuid-v4",
    "user_id": "uuid-v4",
    "access_token": "jwt-token",
```

**인덱스 (Redis Sets)**



### 1.4 보안 고려사항

**비밀번호 정책:**
- 최소 8자 이상
- 대문자, 소문자, 숫자, 특수문자 각 1개 이상
- 일반적인 비밀번호 블랙리스트 검증

**토큰 관리:**
- Access Token: 1시간 (짧은 수명)
- Refresh Token: 7일 (재발급용)
- Refresh Token Rotation (재발급 시 이전 토큰 무효화)
- Token Revocation (로그아웃 시 블랙리스트 등록)

**브루트포스 방지:**
```python

    "count": 3,
    "first_attempt": "2025-01-01T12:00:00Z",
    "locked_until": "2025-01-01T12:15:00Z"  # 5회 실패 시 15분
}
# TTL: 15분
```

## 2. 다중 사용자 격리 (Multi-User Isolation)

### 2.1 요구사항

**기능 요구사항:**
- 사용자별 독립적인 문서 저장소
- 사용자별 대화 이력 격리
- 사용자별 그룹 관리
- 공유 문서 기능 (선택적)

**비기능 요구사항:**
- 사용자 간 데이터 접근 불가
- Redis Key 네임스페이스 분리
- 벡터 검색 시 사용자 필터 자동 적용

### 2.2 데이터 격리 전략

**현재 구조 (Single User)**
```
document:{filename} → metadata
vector:index → all documents
conversation:{conv_id} → conversation data
group:{group_id} → group metadata
```

**신규 구조 (Multi User)**
```
user:{user_id}:document:{filename} → metadata
user:{user_id}:vector:index → user's documents only
user:{user_id}:conversation:{conv_id} → conversation data
user:{user_id}:group:{group_id} → group metadata
```

### 2.3 벡터 검색 격리

**Redis Vector Schema 업데이트**
```python
schema = (
    TextField("$.filename"),
    TextField("$.content"),
    TagField("$.group_id"),
    TagField("$.user_id"),  # 🆕 사용자 ID 필터링
    VectorField("$.embedding",
        "FLAT",
        {
            "TYPE": "FLOAT32",
            "DIM": 1024,
            "DISTANCE_METRIC": "COSINE"
        },
        as_name="vector"
    )
)
```

**검색 쿼리에 사용자 필터 자동 추가**
```python
# Before
query = f"*=>[KNN {top_k} @vector $vec AS score]"

# After
query = f"(@user_id:{{{user_id}}})=>[KNN {top_k} @vector $vec AS score]"
```

### 2.4 미들웨어 구현

**사용자 인증 미들웨어**
```python
from fastapi import Request, HTTPException, Depends
from typing import Optional

async def get_current_user(request: Request) -> dict:
    """JWT 토큰에서 사용자 정보 추출"""
    auth_header = request.headers.get("Authorization")
    if not auth_header or not auth_header.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="Authentication required")

    token = auth_header.split(" ")[1]
    payload = verify_jwt_token(token)  # JWT 검증

    user_id = payload.get("user_id")
    user = await get_user_by_id(user_id)
    if not user or not user["is_active"]:
        raise HTTPException(status_code=401, detail="Invalid user")

    return user
```

## 3. API Key 관리 (API Key Management)

### 3.1 요구사항

**기능 요구사항:**
- API Key 생성/삭제
- 키별 권한 설정 (읽기 전용, 읽기/쓰기)
- 키별 사용량 추적

**비기능 요구사항:**

- 키 해싱 저장 (SHA-256)
- 요청당 API Key 검증

### 3.4 API Key 인증 플로우

**인증 방식 선택**
```python
# 1. JWT Token (웹 UI 사용자)
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# 2. API Key (API 호출자)
X-API-Key: chatbot_abc123def456ghi789jkl012mno345pqr678
```

**미들웨어 구현**
```python
async def authenticate(request: Request) -> dict:
    """JWT 또는 API Key 인증"""

    # JWT 토큰 확인
    auth_header = request.headers.get("Authorization")
    if auth_header and auth_header.startswith("Bearer "):
        return await authenticate_jwt(auth_header)

    # API Key 확인
    api_key = request.headers.get("X-API-Key")
    if api_key:
        return await authenticate_api_key(api_key, request.method)

    raise HTTPException(status_code=401, detail="Authentication required")

async def authenticate_api_key(api_key: str, method: str) -> dict:
    """API Key 검증 및 Rate Limiting"""

    # 1. 키 형식 검증
    if not api_key.startswith("chatbot_") or len(api_key) != 40:
        raise HTTPException(status_code=401, detail="Invalid API key format")

    # 2. 키 해시 조회
    key_hash = hashlib.sha256(api_key.encode()).hexdigest()
    key_data = await redis.hgetall(f"apikey:hash:{key_hash}")

    if not key_data or not key_data.get("is_active"):
        raise HTTPException(status_code=401, detail="Invalid or inactive API key")

    # 3. 만료일 확인
    if key_data.get("expires_at"):
        if datetime.now() > datetime.fromisoformat(key_data["expires_at"]):
            raise HTTPException(status_code=401, detail="API key expired")

    # 4. 권한 확인
    permissions = json.loads(key_data["permissions"])
    if method in ["POST", "PUT", "DELETE"] and "write" not in permissions:
        raise HTTPException(status_code=403, detail="Write permission required")

    # 5. Rate Limiting
    await check_rate_limit(key_data["key_id"], key_data["rate_limit"])

    # 6. 사용 통계 업데이트
    await update_key_usage(key_data["key_id"])

    return {
        "user_id": key_data["user_id"],
        "key_id": key_data["key_id"],
        "auth_type": "api_key"
    }
```

### 4.4 필터링 구현

**필터 적용 순서**
```python
async def query_with_advanced_filter(
    question: str,
    user_id: str,
    advanced_filter: AdvancedFilter,
    top_k: int = 5
):
    # 1. 문서 메타데이터 필터링 (Redis)
    eligible_documents = await filter_documents_by_metadata(
        user_id=user_id,
        advanced_filter=advanced_filter
    )

    if not eligible_documents:
        return {"message": "No documents match the filter criteria"}

    # 2. 페이지 범위 필터링 (해당하는 청크만 선택)
    eligible_chunks = await filter_chunks_by_page(
        documents=eligible_documents,
        page_from=advanced_filter.page_from,
        page_to=advanced_filter.page_to
    )

    # 3. 벡터 검색 (필터링된 청크만 대상)
    embedding = await embed_query(question)
    results = await vector_search(
        embedding=embedding,
        user_id=user_id,
        eligible_chunks=eligible_chunks,
        top_k=top_k
    )

    return results
```

**날짜 필터 구현**
```python
async def filter_by_date(
    user_id: str,
    uploaded_after: Optional[datetime],
    uploaded_before: Optional[datetime]
) -> List[str]:
    """날짜 범위로 문서 필터링"""

    # 모든 문서 메타데이터 스캔
    pattern = f"user:{user_id}:document:*"
    documents = []

    async for key in redis.scan_iter(match=pattern):
        metadata = await redis.hgetall(key)
        uploaded_at = datetime.fromisoformat(metadata["uploaded_at"])

        # 날짜 범위 확인
        if uploaded_after and uploaded_at < uploaded_after:
            continue
        if uploaded_before and uploaded_at > uploaded_before:
            continue

        documents.append(metadata["filename"])

    return documents
```

**페이지 범위 필터 구현**
```python
async def filter_chunks_by_page(
    documents: List[str],
    page_from: Optional[int],
    page_to: Optional[int]
) -> List[str]:
    """페이지 범위로 청크 필터링"""

    if not page_from and not page_to:
        return documents  # 페이지 필터 없음

    eligible_chunks = []

    for doc in documents:
        # 문서의 모든 청크 조회
        chunks = await redis.smembers(f"document:{doc}:chunks")

        for chunk_id in chunks:
            chunk = await redis.hgetall(f"chunk:{chunk_id}")
            page_num = int(chunk.get("page_number", 0))

            # 페이지 범위 확인
            if page_from and page_num < page_from:
                continue
            if page_to and page_num > page_to:
                continue

            eligible_chunks.append(chunk_id)

    return eligible_chunks
```

```python
# Step 1: 기본 관리자 계정 생성

    email="admin@chatbot.com",
    password="secure_password",
    role="admin"
)

# Step 2: 기존 문서를 관리자 계정으로 이전
for old_key in redis.scan_iter(match="document:*"):
    old_data = redis.hgetall(old_key)
    filename = old_key.split(":")[-1]

    # 새 키로 복사
    new_key = f"user:{admin_user.user_id}:document:{filename}"
    redis.hset(new_key, mapping=old_data)
    redis.hset(new_key, "user_id", admin_user.user_id)

    # 기존 키 삭제 (검증 후)
    # redis.delete(old_key)

# Step 3: 벡터 인덱스 재구축
await rebuild_vector_index_with_user_id(admin_user.user_id)
```
