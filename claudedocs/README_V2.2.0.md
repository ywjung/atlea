## 🎯 시작하는 방법

### 신규 개발자

1. **[설계 문서](V2.2.0_DESIGN.md)** 읽기 (30분)
   - 전체 아키텍처 이해
   - 4개 핵심 기능 파악
   - 보안 요구사항 확인

2. **[구현 가이드](V2.2.0_IMPLEMENTATION_GUIDE.md)** 검토 (1시간)
   - 코드 예제 살펴보기
   - 필요한 패키지 확인
   - 데이터 모델 이해

3. **[빠른 시작 가이드](V2.2.0_QUICKSTART.md)** 따라하기
   - 개발 환경 설정
   - Phase 1부터 단계별 진행
   - 체크리스트 활용

### 프로젝트 매니저

1. **[빠른 시작 가이드](V2.2.0_QUICKSTART.md)** → 일정 계획
   - 6주 로드맵 확인
   - 팀원에게 Phase 할당
   - 마일스톤 설정

2. **[설계 문서](V2.2.0_DESIGN.md)** → 기술 사양 검토
   - 클라이언트 요구사항 매핑
   - 리스크 식별

3. **주간 진행 상황 추적**
   - 각 Phase 완료 여부 확인
   - 블로커 해결

### 시니어 개발자

1. **모든 문서 검토** (설계 → 구현 → 빠른 시작)
2. **아키텍처 개선 제안**
3. **코드 리뷰 및 멘토링**
4. **보안 검토 리더십**

## 📊 v2.2.0 기능 요약

### 1. 사용자 인증 시스템
- JWT 기반 토큰 인증
- 회원가입/로그인/로그아웃
- 비밀번호 보안 (bcrypt 해싱)
- 브루트포스 방지

### 2. 다중 사용자 격리
- 사용자별 문서 저장소
- Redis 네임스페이스 분리
- 벡터 검색 자동 필터

### 3. API Key 관리
- API Key 생성/삭제
- 권한 관리 (read/write)
- Rate Limiting
- 사용량 통계

### 4. 고급 필터링
- 날짜 범위 필터
- 페이지 범위 필터
- 파일 형식 필터
- 파일 크기 필터

## 🔧 추가 리소스

### 마이그레이션 스크립트
- 위치: [`../scripts/migrate_to_multiuser.py`](../scripts/migrate_to_multiuser.py)
- 용도: v2.1.0 → v2.2.0 데이터 마이그레이션
- 실행 방법:
  ```bash
  python scripts/migrate_to_multiuser.py \
    --admin-email admin@example.com \
    --admin-password SecurePassword123! \
    --dry-run
  ```
