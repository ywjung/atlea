## ✅ 적용 완료

### 1. 관리자 권한 추가 (2개 엔드포인트)

관리자 전용 기능으로 판단하여 권한을 추가한 엔드포인트:

| API 엔드포인트 | 함수명 | 기능 | 이유 |
|---------------|--------|------|------|
| `/api/documents/upload` | `upload_document` | 문서 업로드 | 관리 작업 - 일반 사용자는 문서 업로드 불필요 |
| `/api/reindex` | `reindex` | 재색인 시작 | 시스템 작업 - 전체 시스템 성능에 영향 |

**적용 코드**:
```python
# 각 함수 시작 부분에 추가됨
redis_client = request.app.state.cache_manager.redis
require_admin(request, redis_client)
```

## 🔓 일반 사용자 접근 유지 (3개 엔드포인트)

읽기 전용으로 일반 사용자도 사용할 수 있도록 **권한을 추가하지 않은** 엔드포인트:

| API 엔드포인트 | 함수명 | 기능 | 이유 |
|---------------|--------|------|------|
| `/api/documents` | `list_documents` | 문서 목록 조회 | 읽기 전용 - 사용자가 문서 목록 볼 수 있어야 함 |
| `/api/groups` | `list_groups` | 그룹 목록 조회 | 읽기 전용 - 사용자가 그룹별 필터링 가능해야 함 |
| `/api/reindex/progress` | `get_reindex_progress` | 재색인 진행 상황 | 읽기 전용 - 사용자가 진행 상황 확인 가능 |

### 미구현 엔드포인트 처리 방안

다음 엔드포인트들은 admin.html에서 호출하지만 백엔드에 존재하지 않습니다:

1. **`/api/auth/admin/stats`** (사용자 통계)
   - 대시보드와 사용자 관리 메뉴에서 호출
   - **권장**: 사용자 통계 API 구현 또는 기존 엔드포인트 활용

2. **`/api/auth/webhooks`** (웹훅 관리)
   - 웹훅 메뉴에서 호출
   - **권장**: 웹훅 기능이 필요하면 구현, 아니면 메뉴에서 제거

### 추가 권장사항

1. **통합 테스트**: 관리자 페이지의 각 메뉴 기능 테스트
2. **사용자 가이드**: 일반 사용자와 관리자의 권한 차이 안내
3. **에러 메시지**: 권한 없음 시 명확한 안내 메시지 표시
